# Contributing to Dating Form

Thank you for your interest in contributing to this dating form project!

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Open `index.html` in a web browser to test the form
4. Make your changes
5. Test all form functionality
6. Submit a pull request

## Development

This is a simple HTML form with:
- HTML5 form validation
- CSS styling for better UX
- JavaScript for interactive features
- No build process required

## Making Changes

1. Create a feature branch from main
2. Make your changes to `index.html`
3. Test the form thoroughly:
   - Test all form fields
   - Test validation rules
   - Test submit functionality
   - Test responsive design
4. Submit a pull request
